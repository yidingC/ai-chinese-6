## Part B · 导航重塑

### 前提

导航不再默认占据底部一整条。

- Nancy 不是 tab，课堂首页就是老师。
- 学习进行中，导航不能和语音入口、字幕争空间。
- 顶层只验证三个去处：`今天 / 练习 / 我的`。
- 日历放进「我的」，小安不占导航。

用同一套画面分别套三种导航模型。每个模型都要有「收起」和「展开」两个状态。

### N1 · 一触即出

- 默认只留一个很小的把手或胶囊，例如左上角或右侧边缘的「课程」。
- 点击后，从边缘展开一张半透明菜单：今天 / 练习 / 我的。
- 菜单盖在画面上，背景压暗，不改变课堂构图。
- 适合课堂进行中：导航存在，但不占常驻空间。

### N2 · 课桌抽屉

- 底部只留一条像抽屉边缘的细把手，不做四个圆按钮。
- 点击或上滑，抽屉从底部抬起，露出今天 / 练习 / 我的。
- 抽屉要有实体感，像从课桌边缘拉开，不是一个普通底部弹层。
- 进入课堂后默认关闭；只有暂停、离开课堂或课间时才能打开。

### N3 · 课堂阶段轨

- 上课时，底部导航位置改为课程阶段：`复习 / 新学 / 练习 / 实战`。
- 它不是目的地导航，而是让学生知道课上到哪了。
- 点当前阶段可以展开「今天 / 练习 / 我的」。
- 下课后阶段轨收回，恢复为应用导航。
- 这是最大胆的一版，用来验证：导航能否随课堂状态改变意义，而不是永远显示同一排 tab。

### 导航验收

- 三种模型都不能常驻抢走底部 60px 以上的内容空间。
- 收起状态不能挡住字幕、语音入口、黑板文字。
- 展开状态必须能一键关闭，不能像新页面一样把课堂彻底切断。
- 三种模型都截「收起 / 展开」两张图。
- 最后总台写一句判断：哪一种最不像普通 App，哪一种最适合继续做。

## Part C · 中英文切换

不另开双语页面。在同一个竖屏试稿里加一个全局语言开关，放在状态栏右侧，不使用底部导航的位置。

### 规则

- 中文始终是学习目标，汉字和拼音任何模式下都不能消失。
- 英文负责界面、提示、解释和释义，不替代中文例句。
- 语言切换不能重载页面，也不能丢失当前 P1/P2/P3、导航和答题状态。
- 语言选择保存在本地，刷新后仍保留。
- 中英双语时，英文只做辅助层级，不能比中文更抢眼。

### 三个模式

1. **中文**：界面、字幕、按钮全中文，隐藏英文释义。
2. **中英**：默认模式。中文为主，英文用小一号字放在下一行。
3. **EN**：界面和讲解用英文，但汉字、拼音和例句仍然保留，因为它们是学习内容。

### 同一屏英文示例

板书标题：

```text
八个词，分三组
Eight words, three groups
```

字幕：

```text
三组立住，八个词就不是八个孤零零的字了。
Once they sit in three groups, these aren't eight loose characters anymore.
```

导航：

```text
今天 / 练习 / 我的
Today / Practice / Me
```

课堂阶段：

```text
复习 / 新学 / 练习 / 实战
Review / Learn / Practice / Apply
```

语音入口：

```text
我在听 · 点一下闭麦
I'm listening · Tap to mute
```

### 板书的双语限制

- 八个词同时出现时，不把八个英文释义全部铺在黑板里。
- `中英` 模式只给当前高亮词或分组标题加一行英文释义；其余词保持汉字加拼音。
- 英文行字号约为中文的 45–55%，不能换行成三行。
- 如果英文把八个词挤乱，就只保留字幕英文，黑板不强制逐词翻译。

### 语言验收

- 同一张 P1 画面分别截：`中文`、`中英`、`EN` 三张图。
- 三张图切换时，老师、板书、导航位置不能跳动。
- 中文模式下没有残留英文；EN 模式下中文例词和拼音仍然在。
- 中英模式下字幕最多两行，不能因为英文变三行。

## DEV 切换

第一组：`P1 讲解 / P2 听你说 / P3 纯黑板`

- 切镜头时只切黑板与老师构图，不切课程内容。
