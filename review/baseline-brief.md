## 硬性画面规则

1. 每屏只有一个主焦点：黑板、音频题、选择题或老师，不能同时抢。
2. 内容多时按讲解节拍逐句出现，不能靠缩小字号硬塞。
3. 板书不滚动。放不下就拆到下一拍，而不是出现滚动条。
4. 黑板安全区约为左侧 `34–650px`、上方 `68–250px`；不能压到 Nancy、右侧导航和底部字幕。
5. 中文字号不小于 20px；重点句 28–44px；拼音 10–12px；英文释义 11–12px。
6. 字幕最多两行。中文为主，英文只在需要解释时出现，不能把整段讲解堆在底部。
7. 选择题 2–3 个，玻璃质感，状态必须能区分「未选 / 已选 / 正确 / 错误」。
8. 所有内容先用静态文字完成；不要求真实语音识别，麦克风只做状态反馈。

## D1 · 生词卡

**目的**：测试单张词卡的最大字段量，确认老师、黑板和字幕仍然分得开。

黑板内容：

```text
点
diǎn

量词 · 钟点

现在八点。
xiànzài bā diǎn.
It's eight o'clock.
```

左下角进度：`生词 1 / 8`。

Nancy 字幕：

> 点，钟点。现在八点。

状态要求：老师指向黑板，词卡集中在左侧；不出现下一张词卡，不出现其他生词预览。

## D2 · 八个词，三组

**目的**：测试单屏最多词汇量。这是本页最重要的一屏。

黑板内容：

```text
八个词，分三组

钟点             日子
点   diǎn        今天   jīntiān
分   fēn         明天   míngtiān
现在 xiànzài     星期   xīngqī
                 号     hào

提问
几   jǐ
```

排版要求：

- 两组主词并排，第三组「提问」单独放在右侧或下方。
- 「几」要有粉笔圈或高亮，是整屏唯一强调。
- 八个词必须一眼能扫完，不能做成轮播。
- 拼音必须和汉字绑定，不能挤到别的词下面。

Nancy 字幕：

> 三组立住，八个词就不是八个孤零零的字了。

交互：点击黑板任意词，字幕换成该词的一句例句；再点一次恢复总讲。当前词只能有一个高亮。

## D3 · 语法对照

**目的**：测试多行句法对比、错误标记和说明同时存在时的层级。

黑板内容：

```text
现在三点。        →    现在几点？
今天十五号。      →    今天几号？

现在是三点。      ✗
现在三点。        ✓

见明天下午。      ✗
明天下午见。      ✓
```

右上角小注：

```text
数字换成「几」，别的字不动
时间放在动词前面
```

Nancy 字幕：

> 问句不用调语序，只把数字换成「几」；时间要放在动词前面。

状态要求：

- 错误行用暖橙色划掉，正确行用粉笔圈住，不能只靠颜色区分。
- 四行必须同时可读；如果挤，只能把两条语法拆成两次点击，不能缩成 14px。
- 此处不出现选择题按钮。

## D4 · 听力策略 + 题

**目的**：测试「板书规则 + 音频 + 问题 + 三个选项」叠加时的层级。

黑板上半：

```text
只抓两样：数字 + 后面那个字

八 + 点 = 钟点
十五 + 号 = 日期
星期 + 三 = 星期三
```

黑板中部是音频入口：

```text
▶  现在几点？现在八点。
```

问题：

> 现在几点？

三个选项：

- `7:00`
- `8:00`
- `10:00`

Nancy 字幕：

> 别逐字翻译。只听数字，再听数字后面那个字。

答错反馈：

```text
八 + 点 = 8:00
```

答对反馈：

> 对。八加点，是钟点。

要求：音频入口、问题、三个选项不能同时挤进黑板；问题与选项放在底部交互区，黑板只保留策略和公式。

```text

第三声 → 第二声

今天几号？    jīntiān jǐ hào?
明天星期三。  míngtiān xīngqīsān.
```

用两条极简粉笔曲线表示 `jǐ` 和 `diǎn`，只做示意，不引入新的复杂图表。

当前跟读句只能高亮一句，其余两句变淡但保留上下文。

Nancy 字幕：

> 写第三声，读第二声。几点，读作 jí diǎn。

底部语音入口：

`我在听 · 点一下闭麦`

不出现「按住说话」。
