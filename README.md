# AI Chinese 6.0 · 概念原型（手机端）

共八个页面：目标选择页 + 选日期页 + 三个目标首页（职场 / 留学 / HSK）+ 准备路线页 + 我的页 + 小安聊天页。流程：目标选择 → 选日期 → 目标首页（倒计时按所选日期实时计算）→ 准备路线 / 每日任务 / 小安 / 我的。
任务详情、真实答题、真实对话、能力测试都不在本版范围——对应入口点击后提示「概念未展开」。

## 打开方式

方式一（推荐）：本地预览服务
- 本机已启动：http://127.0.0.1:5180/
- 以后自己启动：在本文件夹里执行 node serve.cjs，然后打开上面的地址

方式二：直接双击 index.html（不依赖服务，也能完整点着走）

## 页面清单
- index.html —— 目标选择页（四张目标卡；第四张「说说我的目标」暂为概念提示）
- goal-date.html —— 选日期页（?goal=work|study|hsk；日历选日期，推荐＝今天 + 58 / 83 / 72 天；HSK 版带考试场次快捷选择）
- goal-work.html —— 职场目标首页（?days= 可覆盖 58 天；顶部倒计时大卡（天数 + 准备度进度条）+ 放大一档的「今天」卡 + 堆叠日期卡（今天在最上层，前天 / 昨天歪着堆在后面，拖动 / 圆点 / 桌面箭头翻看））
- goal-study.html —— 留学目标首页「今天」（默认 83 天；同模板换内容）
- goal-hsk.html —— HSK 目标首页「今天」（默认 72 天；同模板换内容）
- route.html —— 准备路线页（?goal= 跟随目标：7 站时间线 + 终点说明；全站唯一带返回键的页面）
- profile.html —— 我的页（?goal= 跟随目标：资料卡（学习天数 / 连续打卡 / 已准备能力）/ 学习足迹（最近 13 周热力图，静态演示）/ 我的目标（可回选日期页修改）/ 我的路线 / 我的能力（已能应对 + 在准备中）/ 设置占位）
- xiaolan.html —— 小安聊天页（来自二台样稿，自包含、未改动其设计与交互；底部接入原型导航，小安高亮）

## 设计口径（与需求对齐）
- 首页是新版「今天」逻辑：轻信息行（距离目标天数 ＋ 当前进行站）＋ 每日卡片流（前天 / 昨天 / 今天，默认停在今天，可横向回滑）
- 职场页例外（2026-10-14 改造）：顶部换成倒计时大卡（天数 ＋ 「已准备好 2 / 10 项必要能力」进度条），「当前进行站」入口挪进今天卡卡头；日期卡改「堆叠式」——当前那张正着放、在最上层可点，另外两张歪着堆在后面只露边（不可点），左右拖动跟手、松手吸附，桌面用卡下方小箭头翻看；留学 / HSK 两页仍是原来的轻信息行 + 横向卡片流
- 「今天」卡：4 件事（复习 / 新学 / 练习 / 实战）＋ 时长，圆圈可手动打勾；全部勾完转完成态（还想多练一会）
- 路线按现实准备计划呈现（时间线），不是游戏关卡；无金币 / XP / 排行榜
- 同一套设计系统，三个目标只换强调色与内容：职场＝靛蓝 / 留学＝青绿 / HSK＝琥珀
- 底部导航三个 tab：今天（回顶部）/ 小安 / 我的；跨页链接自动带上 goal / days / date，倒计时口径全局一致；未展开入口统一点击提示「… 概念未展开」
- 顶部带一条手机状态栏（装饰）：时间走真实时钟，5G / 电池为样式示意
- 目标首页是「家」，不设返回键（改目标 / 日期走「我的」）；选日期页与准备路线页左上角保留返回；小安页保持原样（不设返回键）
- 小安聊天页来自二台样稿：样式与交互原样保留（页面自带脚本与提示条），不与原型 app.js 混用；只在页脚接入了统一底部导航
- 手机屏约束（参考 5.0）：内容列封顶 430px 居中；桌面宽屏（≥700px）时收成圆角「手机框」并固定在窗口中间、整机完整可见——外面完全不滚动，状态栏与底部导航钉在框的顶 / 底，中间内容在框内滚动（无滚动条）；手机端为正常页面滚动

## 文件说明
- styles.css —— 设计系统（颜色 / 卡片 / 路线 / 导航 / 提示条）
- app.js —— 轻交互（提示条、今天回到顶部、每日卡片流（留学 / HSK）/ 堆叠日期卡拖动与吸附（职场）/ 今日清单打勾 / 链接参数透传）
- 切页过渡 —— 公区壳（shell.css / shell.js）和设置流程页（styles.css / app.js）都开了跨文档视图过渡：换页时旧页淡出、新页淡入，不再白闪；不支持它的浏览器自动走「换页遮罩」兜底
- serve.cjs —— 本地预览小服务（Node 内置模块，无依赖）
- screenshots/ —— 390 宽手机截图（演示与评审用）
